# Sec. 33-182l. Professional service fees.
The annual fee for the provision of professional services, as defined in section 33-182a, for: Class A is sixty dollars; Class B is one hundred dollars; Class C is one hundred twenty dollars; Class D is one hundred fifty dollars; Class E is one hundred sixty dollars; Class F is one hundred ninety dollars; Class G is two hundred eighty-five dollars; Class H is three hundred seventy-five dollars; and Class I is five hundred sixty-five dollars. The annual fee shall be payable to the State Treasurer.
