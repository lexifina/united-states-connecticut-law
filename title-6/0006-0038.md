# Sec. 6-38. Number of state marshals.
The number of state marshals to be appointed for Hartford County shall not exceed seventy-two; for New Haven County, sixty-two; for New London County, thirty-eight; for Fairfield County, fifty-five; for Windham County, eighteen; for Litchfield County, thirty; for Middlesex County, twenty-one; for Tolland County, twenty-two.
